# Задание 5 (лабораторная работа № 3) — вариант 3

Консольное приложение на языке C с использованием **SQLite3**: сущность **«Государство»** и справочник **«Часть света»** (`area`), связь по полю `area_id`. В таблице государств есть поле **фото** (BLOB): загрузка из файла при вставке и выгрузка в файл по пункту меню.

## Структура проекта (модель КИС)

Логика разнесена по компонентам с чётким разделением ответственности:

| Компонент | Файл | Назначение |
|-----------|------|------------|
| Точка входа, конфигурация пути к БД | `src/main.c` | Запуск, открытие БД, инициализация схемы |
| Слой доступа к данным | `src/db.c`, `include/db.h` | Все SQL-запросы только в коде: подготовленные выражения, параметры |
| Слой взаимодействия с пользователем | `src/menu.c`, `include/menu.h` | Меню, ввод параметров выборок |

Сборка — **Makefile**, цель `make` собирает исполняемый файл `state_app`.

## Сборка и запуск

```bash
cd project5
make
./state_app                 # БД по умолчанию: states_lab3.db
./state_app /путь/к/файлу.db
```

Зависимость: пакет с `libsqlite3` и заголовком `sqlite3.h` (в Arch: `sqlite`).

## Функциональность (требования задания 5)

- Меню операций.
- **SELECT** с параметрами: по `id`, по шаблону (`LIKE`) для названия страны и столицы, по общему полю **`area_id`** (несколько стран в одной части света).
- **INSERT** (в том числе с BLOB фото из файла), **DELETE** по `id`.
- Экспорт BLOB в файл.
- Демонстрация **autocommit**: три последовательных `INSERT`, каждый в своей неявной транзакции.
- Демонстрация **явной транзакции**: `BEGIN IMMEDIATE` — три `INSERT` — `COMMIT`.

При первом запуске создаются таблицы `area`, `state` и добавляются демонстрационные строки (три части света, три государства; у «Беларусь» задан тестовый BLOB с сигнатурой PNG).
