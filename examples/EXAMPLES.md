# Examples

В данном разделе представлены примеры работы с SQLite на языке C.

---

## Example 1 — Подключение к базе данных

Файл: `example1_gr11a_Andrey_Borisovets.c`

Описание:
Пример демонстрирует подключение к базе данных SQLite с помощью функции `sqlite3_open`.
Если база данных не существует, она будет создана автоматически.

Основные функции:
- sqlite3_open
- sqlite3_close
