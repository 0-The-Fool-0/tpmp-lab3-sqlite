# Лабораторная работа ТПМП 3 — SQLite на C

Примеры SQLite C API и консольное приложение для работы с государствами и частями света. Задание 5 показывает параметризованные запросы, импорт/экспорт BLOB и режимы транзакций.

## Технологии и структура

- `examples/` — пять небольших примеров;
- `project5/` — приложение с разделением на `include/` и `src/`;
- `docs/` — контрольные вопросы и протокол;
- C, SQLite3, Make.

## Сборка и запуск

Установите компилятор C, Make и заголовки SQLite, затем:

```sh
cd project5
make
./state_app [путь-к-файлу-БД]
```

Программа создаёт/изменяет локальную базу данных. Встроенная `examples/test.db` исключена из снимка.
